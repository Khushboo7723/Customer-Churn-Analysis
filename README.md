# Customer-Churn-Analysis

## Project Overview
This project focuses on analyzing customer churn in a telecommunications company using Exploratory Data Analysis and Machine Learning.
The objective is to identify factors that influence customer churn and build machine learning models to predict whether a customer is likely to leave the company.

## Objectives
- Analyze customer behavior and churn patterns.
- Perform data cleaning and preprocessing.
- Conduct Exploratory Data Analysis (EDA).
- Perform feature engineering.
- Build and compare machine learning models.
- Evaluate model performance.
- Generate business insights and recommendations.

## Dataset
The dataset contains customer information, including:
- Customer demographics
- Internet and phone services
- Contract details
- Payment methods
- Monthly and total charges
- Customer churn status

## Conclusion
This project analyzes customer churn patterns and uses machine learning models to predict potential customer churn. The findings can help businesses identify customers at risk of leaving and develop effective customer retention strategies.
